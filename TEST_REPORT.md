# Отчет за тестове — StudySpot

Дата: 2026-11-11

## Изпълнено
- `python -m unittest discover -s tests -v`: **9/9 успешни** структурни проверки.
- Проверени: MVC маршрут, Identity, защита на Admin, анти-CSRF атрибути, уникални индекси, SQLite конфигурация, валидации, налични изгледи, липса на публична администраторска парола.

## Неизпълнено (ограничения на средата)
- `dotnet restore`, `dotnet build`, `dotnet test`, стартиране на ASP.NET Core сървър и браузърни тестове.
- Причина: .NET SDK не е наличен; мрежовата среда не позволява инсталация.

## Задължителна проверка на компютър с .NET 8
1. `dotnet restore`
2. `dotnet build --configuration Release`
3. `dotnet run`
4. Регистрация, вход, изход, филтри, детайли, любими, оценки, администраторски CRUD.
5. Опит за Admin без роля (очаква се отказ); невалидна оценка; повторна оценка; повторно любимо.

**Статус:** проект с успешно преминали статични проверки, но без потвърдена компилация или end-to-end проверка.
